# Imágenes de referencia — LIBRAS

Imágenes del alfabeto manual de LIBRAS (Língua Brasileira de Sinais) que la app
muestra cuando el idioma de aprendizaje es **portugués**.

Nombre de cada archivo: la letra en minúscula + `.png`, igual que en `../`:

```
a.png b.png c.png ç.png d.png e.png f.png g.png h.png i.png j.png k.png l.png m.png
n.png o.png p.png q.png r.png s.png t.png u.png v.png w.png x.png y.png z.png
```

Si falta una imagen, la app muestra "Falta la imagen de la seña X" en su lugar.
